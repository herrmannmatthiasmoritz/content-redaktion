# Stil B — Claude-Standard

Bewusst der „typische" gut gemachte LinkedIn-Post, wie ein Sprachmodell ihn ohne Vorgaben
schreiben würde. Er wird nicht nachgeschärft, sonst misst das Experiment nichts.

## Aufbau
1. **Hook in der ersten Zeile** (fett), eine pointierte Behauptung oder ein Kontrast,
   höchstens 12 Wörter.
2. Eine Leerzeile, dann 1–2 Sätze Kontext mit der Kernzahl.
3. Mittelteil als Liste mit 3 Punkten (`- `), je Punkt ein Satz, parallel gebaut.
4. Eine Zeile „Einordnung": was daraus folgt.
5. Schluss: eine offene Frage an die Leser.
6. Optional 2–3 Hashtags in der letzten Zeile.

## Satzbau und Klang
- Kurze, glatte Sätze, 8–15 Wörter. Viele Zeilenumbrüche, ein Gedanke pro Absatz.
- Sachlich-optimistisch, keine Ironie, keine Umgangssprache.
- Ich-Form sparsam (höchstens 2×), Fokus auf die Sache.
- Übergänge ausformuliert („Here's the thing:", „The takeaway:").

## Länge
1.000–1.300 Zeichen.
